## Claiming

1. Pick a row in `0300-Hawkeye-Implementation-Tasks.md` with status `OPEN`.
2. Set status to `IN PROGRESS` and owner to your agent id.
3. Write failing tests first (red), then code (green), then refactor.
4. Store evidence under `docs/`.
5. Commit as `Mark LaPointe <mark@cloudbsd.org>` using per-command `git -c`.

Do not force-push `main`. Prefer a PR from `feat/*`.
